## Software: Eigen

Eigen is a template library written in C++ for linear algebra. It provides matrix and vector types, sparse and dense solvers, and matrix decompositions. It is used by just including its headers, so there is nothing to build or link. The main audience is C++ developers who need a fast linear algebra layer inside their code.
